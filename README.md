# bread-docs

The documentation website for [Bread Cooperative](https://bread.coop), live at **[docs.bread.coop](https://docs.bread.coop)**.

## What this is

An open, editable knowledge base covering Bread Cooperative's structure, the BREAD token, solidarity primitives (crowdstaking, angel minters, member projects), and the cooperative's governance. Anyone can read it; anyone with a GitHub account can propose improvements.

## How to get involved

- **Found a typo or want to add a page?** See [Contributing](./CONTRIBUTING.md) for the two ways to make changes — content edits via the Keystatic web editor (no coding required), or code/config edits via a standard pull request.
- **Want to know how decisions get made?** See [Governance](./GOVERNANCE.md) for the merge policy and who can approve changes.
- **Working on the codebase with an AI agent?** See [AGENTS.md](./AGENTS.md) for the full technical reference — project layout, build commands, design system, plugin docs, and the end-to-end editing workflow.
